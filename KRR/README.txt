# Case-Based Reasoning System for Technical Support

KRR (Knowledge Representation and Reasoning) mini-project website.

## Files
- `index.html` — main website
- `style.css` — responsive styling
- `script.js` — interactive CBR case-retrieval demo

## How to run
1. Keep all three files in the same folder.
2. Double-click `index.html`.
3. The website opens directly in a browser. No server or internet connection is required.

## Demo
Enter a technical problem or use one of the quick examples. The JavaScript engine compares the input with the sample case library and displays the closest case, match percentage, cause, and reused solution.

## Educational note
The matching engine is a simplified demonstration for a KRR/CBR project. It uses keyword and phrase similarity rather than a production machine-learning model.
